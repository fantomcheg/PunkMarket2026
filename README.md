# 🛒 PunkMarket - Обучающий маркетплейс

**Punkration Vulnerable Marketplace** - образовательная платформа для изучения веб-уязвимостей на примере интернет-магазина.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера разработки

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 3. Сборка для продакшена

```bash
npm run build
npm start
```

## ✨ Возможности

### 🎯 Два режима обучения

#### 🔴 Red Team Mode (по умолчанию)
- **Роль**: Bug Hunter / Pentester
- **Цель**: Найти уязвимости и захватить флаги
- Работа с готовым приложением без редактирования кода
- Бэкенд не выбирается (одинаково уязвим на всех стеках)

#### 🔵 AppSec Mode
- **Роль**: Secure Developer / AppSec Engineer
- **Цель**: Найти, exploit и исправить код
- Выбор backend стека для редактирования (Node.js / Java / PHP)
- Доступ к исходному коду через X-Ray
- Возможность отправить исправленный код на проверку

### 🔍 X-Ray режим
Наведите курсор на любой элемент с синей подсветкой, чтобы увидеть:
- Backend код (Node.js / Java / PHP)
- Endpoint и контроллер
- Уязвимости (CWE паттерны)
- Поток данных
- Валидацию

### 🤖 AI-Coach
Плавающая кнопка справа внизу:
- Задавайте вопросы о безопасности
- Получайте объяснения уязвимостей
- Быстрые вопросы о SQL Injection, XSS, IDOR и др.

### 🎯 BackendSelector
Переключайтесь между стеками:
- **Node.js** (NestJS + Express)
- **Java** (Spring Boot)
- **PHP** (Laravel)

Одинаковый фронтенд, разные backend реализации с теми же уязвимостями.

## 🔓 Уязвимости для обучения

Проект содержит реализации следующих CWE паттернов:

1. **CWE-89**: SQL Injection (поиск)
2. **CWE-200**: Information Disclosure (API категорий)
3. **CWE-307**: Broken Authentication (login без rate limiting)
4. **CWE-208**: Timing Attack (разное время ответа)
5. **CWE-639**: IDOR (доступ к чужим данным)
6. **CWE-362**: Race Condition (корзина)
7. **CWE-943**: NoSQL Injection (фильтры)

## 🛡️ X-Ray метаданные

Каждый элемент с `data-xray-id` содержит:
- Endpoint и метод HTTP
- Backend код с уязвимостями
- Список CWE паттернов
- Уровень сложности эксплуатации
- Описание уязвимости
